## Every chapter follows

**Beginner → Core operations → Patterns → Intermediate → Advanced → Important questions → TC/SC → Pitfalls → Recognition checklist**

### Coding policy

- **C++ only**.
- Prefer one canonical implementation/template per technique.
- Avoid repeating the same implementation across many questions.
- Focus on intuition, invariant, pattern recognition, and complexity rather than code memorization.

### Complexity policy

Every important problem explicitly states **time complexity (TC)** and **space complexity (SC)**. Output space is distinguished from auxiliary space where it matters.

### Recommended practice loop

```text
Learn concept
    ↓
Implement once from memory
    ↓
Solve beginner questions
    ↓
Recognize the pattern on intermediate questions
    ↓
Solve advanced questions
    ↓
Review mistakes + edge cases
    ↓
Re-solve without notes
```
