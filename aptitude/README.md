## How to Prepare

```text
Learn concept
    ↓
Memorize only useful formulas / patterns
    ↓
Solve untimed examples
    ↓
Identify shortcuts and traps
    ↓
Solve timed sets
    ↓
Review mistakes
    ↓
Repeat weak topics
```

### Recommended practice cycle

- **Foundation:** understand formulas and standard patterns.
- **Speed:** target easy/medium questions with strict time limits.
- **Accuracy:** maintain an error log for careless mistakes.
- **Mixed practice:** combine topics so pattern recognition is tested.
- **Mock tests:** reproduce campus-placement/company-test conditions.

### Question-solving rule

Do not memorize only the final answer. Record:

1. The underlying concept.
2. The fastest reliable method.
3. Why the distractor answers are wrong.
4. The mistake you made, if any.

## Exam Strategy

For a typical timed aptitude test:

```text
1. Scan the section.
2. Solve high-confidence questions first.
3. Skip calculations that are becoming disproportionately long.
4. Use elimination before full calculation when safe.
5. Track time per section.
6. Return to difficult questions only after securing easy marks.
```

Always follow the actual test's negative-marking and calculator rules instead of assuming a generic policy.
